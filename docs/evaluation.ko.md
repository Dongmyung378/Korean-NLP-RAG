# 평가 방법

[English](evaluation.md)

공개 KorQuAD v1 검증 자료에서 구성하고 동결한 프로젝트 평가 세트를 사용합니다. 동일한 원문 문단과 정규화 후 같은 질문은 하나의 그룹으로 유지합니다. 최종 세트에서는 기존 1,000문항 평가나 최초 학습 자료에 노출된 그룹을 제외했습니다. 최종 정답 문단을 포함한 원문 960개는 모두 검색 대상에 남겨 둡니다.

| 정의된 세트 | 문항 수 |
| --- | ---: |
| 중복 노출 제거 후 사용 가능한 공식 학습 자료 | 60,387 |
| 정답이 있는 개발 세트 | 304 |
| 정답이 있는 최종 세트 | 501 |
| 정답이 없는 합성 개발 세트 | 80 |
| 정답이 없는 합성 최종 세트 | 80 |

전체 비교의 분모는 개발 384문항, 최종 581문항입니다. 문단 그룹을 나누지 않기 위해 정답이 있는 질문의 목표 수 300개와 500개를 소폭 초과했습니다. 제한된 학습 실험은 공식 학습 자료에서 뽑은 3,002문항과 별도의 내부 검증 206문항을 사용합니다. 프로젝트 개발 및 최종 질문은 해당 학습 자료 구성에 포함하지 않습니다.

Exact Match와 문자 단위 F1은 KorQuAD의 공식 한국어 정규화와 복수 정답 중 최대 점수를 적용합니다. 정답이 있는 질문에서 답변을 보류하면 0점입니다. 검색 Recall, MRR, nDCG의 관련 청크는 올바른 문단에 속하고 주석의 정답 구간 전체를 포함해야 합니다. 일부 구간만 겹치면 관련 청크로 인정하지 않습니다. 정답 질문의 답변률, 반환한 답변의 정확도, 정답 없음의 오답 반환률을 구분하여 제시합니다. Wilson 구간은 참고용이며 서로 관련된 질문이나 합성 질문에 대한 통계적 유의성을 입증하지 않습니다.

Reader 점수는 시작 및 끝 토큰의 확률을 곱하여 답변을 선택하는 데 사용합니다. 답변이 의미상 정확할 확률로 보정된 값은 아닙니다. 인용한 구간이 원문에 존재하더라도 질문이 요구한 대상이나 관계에 대한 정답이라는 의미는 아닙니다.

설정 선택에는 개발 질문만 사용합니다. 검색 성능은 1%p, 답변 EM은 1%p 이상 개선되어야 합니다. EM 감소 없이 문자 F1이 0.5%p 이상 개선되는 경우도 허용합니다. 청크 설정 4개, Reader 설정 4개, 보류 기준 조합 12개로 탐색을 제한합니다. 보류 기준을 채택하려면 정답 없음의 오답 반환률이 최초 모델보다 높아지지 않고, 정답 질문의 답변률이 최초 모델 대비 2%p 넘게 줄어들지 않아야 합니다. Reader 후보에는 고정된 `1e-6`의 CLS 점수 여유값을 적용하고 최초 대조 모델은 기존 값 0을 유지합니다. 후보와 대조 모델은 동일한 장치에서 비교합니다.

최초 보류 기준 12개는 모두 종합 채택 조건을 충족하지 못했습니다. 이후 별도의 [calibration-v2 선언](../configs/calibration-v2.json)을 통해 동일한 개발 캐시에서 더 엄격한 조합 9개만 추가 검증했습니다. 선택된 Reader와 기존 품질 기준, 답변률 기준, 동일 GPU의 오답 반환률 기준은 그대로 유지했습니다. 따라서 보류 기준의 전체 탐색 수는 최초 12개와 후속 9개이며, 최초 계획 안에서 성공한 것으로 표현하지 않습니다. 최초 실패 기록은 모두 변경 없이 보존했고, 추가 후보 6개가 조건을 충족하여 EM이 가장 높은 후보를 선택했습니다. [개발 단계 보정 보고서](../reports/development-calibration.ko.md)에 전체 결과를 제공합니다. 동일한 개발 데이터에 맞춰 후속 탐색을 했으므로 개발 성능이 낙관적일 수 있으며, 최종 평가는 설정을 고정한 뒤 수행하여 별도로 보고합니다.

완료된 [최종 비교 검증](../reports/final/final-comparison.json)에서 정답 질문의 EM은 312/501에서 367/501로, 문자 F1은 70.55%에서 79.94%로 높아졌습니다. 다만 합성 정답 없음 질문의 오답 반환은 1/80에서 4/80으로 늘었습니다. 개발 단계에서 유지한 오답 반환률 조건이 이 최종 합성 질문에서는 유지되지 않았으며, 최종 결과를 보고 보류 기준을 다시 조정하지 않았습니다. 비교를 위해 최초 설정도 재현할 수 있습니다. 문단 단위 부트스트랩 구간과 질문별 개선 및 악화 건수를 함께 제공하지만, 공개 사전학습 모델의 데이터 노출이나 같은 문서에 속한 질문 간 의존성을 없애 주는 것은 아닙니다.

공개 E5 검색기와 더 긴 청크 및 질문 길이를 함께 적용한 후보는 여러 요소가 바뀐 시스템 비교입니다. 이때의 개선을 검색기 학습만의 효과로 해석하지 않습니다. 두 시스템은 동일한 원문과 질문 명세, 정답 청크 판정 기준을 사용하며, 제한된 Reader 비교 전에 재정렬 모델과 Reader 대조 설정을 유지합니다.

최종 질문에 접근하기 전에 채택할 설정, 두 평가 세트의 연결 정보, 전체 모델 묶음의 명세와 추론 및 평가 소스 해시를 동결합니다. 최종 명령은 모델을 불러오거나 최종 질문을 읽기 전에 설정 탐색용 캐시와 불완전하거나 변경된 동결 기록을 거부합니다. 최초 및 채택 모델의 사전에 정한 비교 1회를 보존하고, 개발 과정에서 탈락한 실험도 기록합니다. 최종 결과로 설정을 다시 선택하지 않습니다.

```powershell
python -m scripts.evaluate_portable --bundle PATH_TO_BUNDLE --benchmark PATH_TO_BENCHMARK --split dev --no-answer PATH_TO_NO_ANSWER/dev.jsonl --output NEW_DEV_OUTPUT --device cpu
python -m scripts.evaluate_portable --bundle PATH_TO_FROZEN_BUNDLE --benchmark PATH_TO_BENCHMARK --split final --no-answer PATH_TO_NO_ANSWER/final.jsonl --freeze PATH_TO_FREEZE_JSON --output NEW_FINAL_OUTPUT --device cpu
```

각 실행은 예측과 Reader 캐시의 해시, 질문 및 평가 세트의 연결 정보, 실제 실행 환경과 분모가 있는 지표를 저장합니다. 검증한 로컬 모델 묶음으로 실행하며 Docker는 필요하지 않습니다. 파일 해시를 재현해도 서로 다른 장치에서 동일한 비트 단위 결과를 보장하지는 않습니다. 응답 시간은 모델 로딩 시간을 제외하며, 여러 Reader 경로를 실행한 개발 캐시의 시간은 별도 범위로 설명합니다.

이 평가는 공식 비공개 시험이나 사전학습 모델이 처음 보는 자료라는 증거가 아닙니다. 개발과 최종 세트 사이에 원문 기사 19개가 겹치며, 공개 KorQuAD 학습 모델이 검증 자료를 접했을 가능성도 있습니다. [정답 없음 세트](../reports/no_answer_methodology.ko.md)는 합성 질문을 이용한 고정 지식베이스 검증입니다. 기존에 노출된 질문 6개는 최종 분모에서 제외합니다. 실제 측정한 최종 수치는 저장한 결과 보고서에서 확인하며, 이 문서에는 미측정 성능을 기재하지 않습니다.
