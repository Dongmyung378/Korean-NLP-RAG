# 최초 개발 모델

[English](legacy_baseline.md)

이 프로젝트의 최초 개발 기간은 2026년 6월, 4주입니다. 최초 소스는 `de511597bf7556076aaa4c917ddcc12dd98c041e` 리비전으로 구분합니다. STS로 학습한 KLUE-RoBERTa 검색기와 이진 분류 재정렬 모델, 짧은 청크 5,889개, BM25, FAISS, RRF, 공개 KorQuAD 학습 KoELECTRA Reader를 사용했습니다.

과거 개발용 검색 질문 1,000개에서는 결합 검색과 재정렬의 Recall@5가 90.2%, Recall@20이 93.5%, MRR@10이 0.7795였습니다. 새 평가와 질문 구성이 다르므로 같은 조건의 개선 비교에 사용하지 않습니다.

저장된 로컬 회귀 검증 100문항에서는 79개에 답했습니다. 기존 정답 문자열 포함 수치는 67/100이며, 답변한 질문만 기준으로 하면 67/79입니다. 동일한 저장 답변에 공식 정규화를 적용하면 EM 63/100, 문자 F1 68.54%, 반환 답변의 EM 63/79인 79.75%입니다. 정답 문자열 포함 여부와 정확한 일치, 의미적 정확성은 서로 다른 지표입니다.

기존 보류 점검 질문 6개에서는 5개를 보류했습니다. 팬클럽 해체식 질문에 창단식 날짜를 반환하는 오류가 있었습니다. 이미 확인한 회귀 점검 사례이므로 새로운 합성 질문 평가와 분모를 합치지 않습니다.

과거 무작위 오답 학습 비교에는 평가 질문 중복이 있었습니다. 새 무작위 오답과 어려운 오답 추가 학습은 같은 질문과 정답 본문, 초기 모델과 학습 조건을 사용하며 문단 단위로 내부 검증을 분리합니다. 두 방식 모두 기존 어려운 오답 학습 모델에서 시작하므로, 이번 비교는 추가 학습의 효과를 확인하는 범위입니다.

원본 노트북과 출력 자료는 로컬에 보존했습니다. 공개 저장소에는 재현 방법과 측정 결과, 평가의 한계를 중심으로 정리합니다. 이후 유지보수 날짜를 최초 개발 기간에 포함하지 않습니다.
