# 실행 환경 검증

[English](environment-verification.md) | [한국어](environment-verification.ko.md)

동결된 최종 선택 모델이 서로 분리된 Windows와 Linux의 깨끗한 CPU 환경에서 오프라인 실행 검증을 통과했습니다. 동일한 동결 소스와 검증된 모델 파일을 사용했으며, 사전에 지정한 개발 질문 두 개를 각 환경에서 두 번씩 실행해 총 여덟 번 추론했습니다. 운영체제 간 답변 문자열, 답변 또는 보류 판단, 인용 식별자가 일치했고 반복 실행의 답변도 같았습니다.

| 측정 항목 | Windows | Linux |
| --- | --- | --- |
| Python | 3.12.7 | 3.12.15 |
| PyTorch | 2.14.0+cpu | 2.14.0+cpu |
| CPU 스레드 | 4 | 4 |
| 완료한 추론 | 4회 | 4회 |
| 모델 적재 | 14.44초 | 11.83초 |
| 프로세스 최대 메모리 | 2.05 GiB | 1.64 GiB |
| 두 번째 질문 쌍의 중앙 추론 시간 | 3.04초 | 3.29초 |

다른 개발 작업이 진행될 수 있는 환경에서 소규모 실행 검증으로 얻은 프로세스 측정값입니다. Windows의 최대 working set과 Linux의 최대 RSS는 운영체제의 집계 방식이 다릅니다. 최소 하드웨어 사양이나 전체 질문 집합의 지연 시간으로 해석하지 않습니다. 첫 질문 쌍에는 최초 처리의 영향이 있으며 JSON 기록에는 모든 추론 시간이 보존됩니다.

관측된 점수 차이의 최댓값은 Reader 선택 점수 1.74e-06, reranker 점수 1.19e-07였습니다. 수치 연산 환경에 따라 점수의 비트 단위 일치까지 보장하지는 않으며, 이번 네 번의 대응 비교에서는 최종 판단과 답변이 모두 같았습니다.

모델 manifest의 SHA-256은 `2834c057f845137c129dcbbd6bc419e0a63303779d0a2f31a0b7cff11a4a57b9`이며 canonical 동결 식별자는 `e2304cebdc5ed6af713f0a6a3376d15849394f882c718c81ce5ad4963d2b0574`입니다. JSON 파일의 바이트 해시는 별도로 기록합니다. 동결 내용, 소스, 설정과 모델 결합을 검증했고 이번 확인에서는 최종 성능 평가용으로 분리한 질문을 읽지 않았습니다.

앞선 별도 실행 스크립트 검증에서는 PATH에 Python이 없는 Windows x64와 Linux x64에서 자동 준비도 실제 수행했습니다. 고정된 uv 파일을 검증하고 Python 3.12.15를 프로젝트 내부에 설치했으며 순수 CPU 환경을 구성해 `pip check`까지 통과했습니다. 최종 공개 다운로드와 처음 실행 과정은 메타데이터 및 명세를 배포한 뒤 별도로 기록합니다.

Linux는 같은 컴퓨터에서 Docker를 이용해 검증 환경만 분리했습니다. 일반 사용자는 Docker 없이 실행합니다. 서로 다른 실행 환경을 확인한 검증이며 외부 제3자의 독립 검토나 모든 입력과 하드웨어를 검사했다는 의미는 아닙니다. 간결한 증거는 [environment-verification.json](environment-verification.json), 실행 방법은 [runtime.ko.md](../docs/runtime.ko.md)에서 확인할 수 있습니다.
